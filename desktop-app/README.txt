VISIONFORGE OS DESKTOP 0.13.0

Aplicativo Electron para Windows 10/11 x64.

Recursos:
- login conectado ao VisionForge OS;
- SQLite local e fila offline;
- sincronização incremental;
- proteção contra operações duplicadas;
- detecção e resolução de conflitos;
- arquivos locais com upload posterior;
- módulos operacionais;
- equipe, notificações e permissões;
- Minha conta e logout seguro.

Build no Windows:
  npm install
  npm run dist:win

O instalador NSIS será criado em desktop-app/dist/ como VisionForge-OS-Setup-0.13.0.exe.
